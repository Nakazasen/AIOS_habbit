# Handover

> First-read: skip. Handover canonical: `PROJECT_HANDOVER.md`. Thư mục này là bản ghi phase cũ.

Lưu handover theo phase hoặc theo mốc quan trọng.

Mỗi handover nên có:

- Current phase.
- Completed work.
- Pending work.
- Risks.
- Decisions.
- Validation result.
- Next steps.
- Rollback.
