# Quy Trình Cổng Giai Đoạn (Phase Gate Process)

Lệnh `aios-habit phase validate --phase N` thực hiện kiểm tra thực tế các sản phẩm chuyển giao (deliverables). Một giai đoạn sẽ bị đánh giá thất bại (FAIL) khi thiếu các tài liệu, module, hành vi kiểm chứng, fixture kiểm toán hoặc nội dung bàn giao bắt buộc.
