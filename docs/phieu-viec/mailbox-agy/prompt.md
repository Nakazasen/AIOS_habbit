# Mailbox thợ agy

Mailbox này của thợ **agy** (máy nhà, chế độ 4 watcher song song).
Model: **gemini-3.8-flash-high**; việc khó chuyển sang **claude-sonnet/opus-5.5-medium**.

Vé thật đầu tiên sẽ được Muse ghi đè vào file này.

Quy ước: mỗi thời điểm chỉ 1 vé active trên mailbox này; thợ nhận vé đặt `dang-lam` NGAY + timestamp vào `ghi_chu` rồi push (watcher canh kẹt 20 phút); xong thì `xong-cho-duyet` + báo cáo vào `ket-qua/`.
